# CCTV 6 频道精简直播源（GitHub 自动更新版）

只保留 CCTV-1 / 2 / 3 / 4 / 8 / 13 六个央视高清频道，无广播电台、无聚合广告频道。GitHub Actions 每天自动实测并更新，APTV 里只需填一条订阅链接。

---

## 一、原理

```
公开M3U源池(多个) → 脚本解析出6频道 → 并发实测可用性/延迟 → 选最优源 → 写出 cctv.m3u
                                                                    ↓
                                          GitHub Actions 每天定时运行并提交 → raw 链接给 APTV 订阅
```

- 每天北京时间 06:22、18:22 各更新一次，另可手动触发。
- 每次重新实测：失效源自动被剔，选延迟最低的可用源。
- 若某频道当天找不到任何可用源，保留上一次结果，不会把列表改空。

## 二、部署步骤（GitHub）

1. 登录 GitHub，新建一个**公开**仓库，例如 `cctv-iptv`。
2. 把本目录内所有文件（含 `.github` 隐藏文件夹）上传到该仓库。
   - 用网页上传时，`.github` 文件夹需单独建：网页新建文件，路径填 `.github/workflows/update.yml`。
3. 进入仓库 **Settings → Actions → General**，在 **Workflow permissions** 勾选 **Read and write permissions**，保存。
   - 这一步是让定时任务有权限把更新的文件提交回仓库，必做。
4. 进入 **Actions** 标签页，确认 workflow 已启用；点右侧 **Run workflow** 手动跑一次。
5. 等运行完成（约 1-2 分钟），打开 `cctv.m3u` 文件，点 **Raw** 按钮，复制浏览器地址栏的完整链接。
   形如：`https://raw.githubusercontent.com/你的用户名/cctv-iptv/main/cctv.m3u`

## 三、APTV 订阅配置

1. 打开 APTV → 底部 **配置** → 右上角 **+** → **订阅配置**。
2. 配置链接填上面复制的 raw 链接。
3. 任意填一个配置名称，如 `央视6台`。
4. 节目单地址填 `https://epg.aptv.app/pp.xml.gz`。
5. **打开「自动刷新配置」**（关键：APTV 每 8 小时或打开应用时自动拉取最新列表）。
6. 保存后，点一下该配置，使其右侧出现绿色启用标志。
7. 返回 **频道**，即可看到 6 个央视频道。

## 四、自定义源池（可选）

若自带的公开源池不够用，可在同目录新建 `pools.txt`，每行一个 M3U 地址，脚本会与内置源池合并后一起检测。例如：

```
https://example.com/your-list.m3u
```

## 五、关于广告（重要，先说清）

| 类型 | 能否去除 | 说明 |
| --- | --- | --- |
| 聚合源里的博彩/购物/垃圾广告频道 | 已去除 | 本列表只有 6 个指定频道，不含任何其他频道 |
| 央视频道自身播出的商业广告 | 无法去除 | 属于官方直播信号的一部分，任何直播源都一样；想看无广告正片需用回看/点播，属另一方案 |

## 六、合规与风险提示

- 本仓库不托管任何视频流，仅保存脚本和一份指向公开地址的播放列表；地址来自社区公开维护的源池。
- 第三方直播源的稳定性、版权合规性由源站负责，**待核实**；请仅作个人学习研究使用，勿用于商业用途或二次分发。
- 若所在网络无法访问某些源（如运营商封锁），脚本会自动切换到可用的源；若全部不可用，会保留上次结果并可在 Actions 日志中查看原因。

## 七、文件清单

| 文件 | 作用 |
| --- | --- |
| `update.py` | 采集、实测、筛选、生成 M3U 的核心脚本 |
| `cctv.m3u` | 生成的订阅文件，APTV 订阅的就是它 |
| `.github/workflows/update.yml` | 每天定时运行 update.py 并提交 |
| `pools.txt`（可选） | 自定义源池地址，一行一个 |
